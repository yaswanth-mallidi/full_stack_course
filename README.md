# Full Stack Course

Welcome to the **Full Stack Course** repository! This repository serves as a practical log and showcase of web development exercises, moving from core HTML structures to modern interactive web layouts.

---

## 📂 Repository Content & Overview

Below is a breakdown of each test file and the web development concepts covered in them:

### 1. `test1.html` — HTML Foundations & Document Structure
* **Focus:** Understanding essential HTML elements and document boilerplate.
* **Key Topics Covered:**
  * Basic page layout using HTML tags (`<html>`, `<head>`, `<body>`)
  * Text formatting, headings (`<h1>` to `<h6>`), and paragraphs (`<p>`)
  * Structuring ordered (`<ol>`) and unordered (`<ul>`) lists
  * Working with hyperlinks (`<a>`) and inline image embeds (`<img>`)

### 2. `test2.html` — Forms, Tables & Data Presentation
* **Focus:** Handling structured data display and capturing user inputs.
* **Key Topics Covered:**
  * Building complex HTML tables (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<td>`, `<th>`)
  * Creating interactive user forms (`<form>`, `<input>`, `<textarea>`, `<button>`)
  * Form element attributes (types: `text`, `email`, `password`, `submit`, along with placeholders and validation tags)
  * Selection UI components (`<select>`, `<option>`, radio buttons, checkboxes)

### 3. `test3.html` — CSS Integration & Layout Design
* **Focus:** Styling HTML elements and structuring visual layouts.
* **Key Topics Covered:**
  * Applying Inline, Internal, and External CSS stylesheets
  * CSS Box Model fundamentals (margin, padding, border, content area)
  * Basic positioning properties (`static`, `relative`, `absolute`, `fixed`)
  * Flexbox/Grid layout practices for creating responsive, multi-column web pages

### 4. `test4.html` — Semantic HTML & Modern Web Elements
* **Focus:** Advanced structural markup, semantic accessibility, and media integration.
* **Key Topics Covered:**
  * Semantic sectioning elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
  * Embedded media tags (`<audio>`, `<video>`, `<iframe>`)
  * Accessibility features (ARIA attributes and `alt` text standards)
  * Synthesis of previous concepts into a structured, responsive web layout
